# Semana 2

## Entrega: página tipo Google (HTML + CSS)

Maqueta de la página de inicio de Google hecha con HTML semántico y CSS básico.

**Archivos**

- [index.html](index.html): estructura de la página (`header`, `main`, `footer`, buscador).
- [styles.css](styles.css): estilos de la página.
- [Google-Logo.png](Google-Logo.png): logotipo usado en la página.

**Cómo revisarla**

Descargue los tres archivos en la misma carpeta y abra `index.html` en el navegador. No requiere instalación ni conexión a internet.
