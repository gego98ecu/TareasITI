## Para el profesor

El repositorio es público: se puede consultar sin invitación.

- Abra la carpeta de la semana para revisar sus archivos.
- Para descargar todo, use **Code → Download ZIP** o [descargue el ZIP de la rama main](https://github.com/gego98ecu/TareasITI/archive/refs/heads/main.zip).
- Para descargar un archivo, ábralo y use **Download raw file** cuando esté disponible.

## Subir tareas

1. Abra la carpeta de la semana correspondiente.
2. Seleccione **Add file → Upload files**.
3. Añada los archivos y confirme con **Commit changes** en la rama `main`.
4. Actualice el README de esa semana con una breve descripción de la entrega y, si corresponde, instrucciones para ejecutarla.

Las carpetas están preparadas para las entregas; sus README iniciales no representan tareas entregadas.
