# Semana 4

Sistema Académico ITI en React.js: módulos de **Estudiantes** y **Materias** con tablas y ventanas modales de Bootstrap.

## Contenido

- [sistema-academico-iti/](sistema-academico-iti/): proyecto React + Vite.
- [CONTROL_DE_CAMBIOS.md](sistema-academico-iti/CONTROL_DE_CAMBIOS.md): detalle de todos los cambios realizados y su explicación.

## Actividades

1. Visualización y actualización de estudiantes (tabla, botón Actualizar, cédula bloqueada).
2. Registro de nuevos estudiantes en ventana modal, con validaciones.
3. Nuevo módulo de Materias (código, nombre, descripción, créditos y estado).
4. Formularios de registro y actualización en ventanas modales de Bootstrap.

## Cómo ejecutarlo

```bash
cd semana-04/sistema-academico-iti
npm install
npm run dev
```

Abrir http://localhost:5173/, pulsar **Ingresar al sistema** y elegir **Estudiantes** o **Materias** en el menú.
