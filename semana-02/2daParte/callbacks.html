Callbacks

Un callback es una función que se le pasa a otra para que la ejecute cuando termine algo. Aquí: saludar después de 2 segundos.

    Mientras esperas, prueba que la página sigue viva:

    ¿Qué está pasando?

    1. Al pulsar el botón se escribe "Iniciando".

    2. esperarYSaludar recibe una función (el callback) y se la entrega a setTimeout.

    3. JavaScript no se detiene: durante 2 segundos puedes seguir haciendo clic en el otro botón.

    4. Pasado el tiempo, JavaScript "devuelve la llamada" y ejecuta el callback: alTerminar. Ahí aparece "Terminado".
